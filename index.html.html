สูตรย่อทางการแพทย์
MKD = mg/kg/Day (มก./กก./วัน)
MKdose = mg/kg/dose (มก./กก./ครั้ง)

วิธีนำ Web App ขึ้น GitHub Pages ฟรี

เปิดเป็นลิงก์เว็บใช้งานได้ตลอดเวลา ทั้งในคอมพิวเตอร์และมือถือ

เว็บนี้ถูกออกแบบให้อยู่ในไฟล์เดียว (Single-file HTML)

ไม่ต้องลง Node.js หรือ build เครื่องมือใดๆ เพียงแค่อัปโหลดไฟล์ชื่อ index.html ขึ้น GitHub ก็พร้อมใช้งานทันที

1

สร้าง Repository บน GitHub

เข้าเว็บ github.com/new ตั้งชื่อ เช่น pedia-calculator เลือกเป็น Public แล้วกด Create repository

2

อัปโหลดไฟล์ index.html

กดปุ่ม Add file > Upload files แล้วลากไฟล์ index.html นี้ลงไป จากนั้นกดปุ่มสีเขียว Commit changes

3

เปิดใช้งาน GitHub Pages

ไปที่แท็บ Settings > เมนูซ้าย Pages > ในหัวข้อ Branch ให้เลือก main (หรือ master) และโฟลเดอร์ /(root) แล้วกด Save

การติดตั้งเป็นแอปบนมือถือ (Add to Home Screen)

  • iPhone (Safari): กดปุ่มแชร์ (Share) > เลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  • Android (Chrome): กดจุด 3 จุดมุมขวาบน > เลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
คัดลอกข้อความสำเร็จ
ตารางอ้างอิง: ขนาดยาเด็กที่ใช้บ่อย โรงพยาบาลชัยนาทนเรนทร
คำเตือน: โปรแกรมนี้พัฒนาขึ้นเพื่ออำนวยความสะดวกในการคิดคำนวณเบื้องต้น บุคลากรทางการแพทย์ควรตรวจสอบสภาวะผู้ป่วยก่อนสั่งใช้ยาเสมอ
